# README: show what the agent does and how well, with real numbers

**Goal:** someone who opens the GitHub repo understands in two minutes what the agent does, how reliable it is
(measured, not claimed), how it works, and how it was built with Claude Code. The README is the front page of
the demo, so every number in it comes from `evals/runs/` and every claim links to the file that proves it.

## Who reads it

A hiring engineer or CTO who knows LLM apps: skims the top, looks at the screenshots and the results table, then
maybe opens the architecture or one plan. Short sections, tables over prose, no marketing words.

## Screenshots: how

- App screenshots: run `npm run dev` on port 3010 against the existing `local.db` demo leads, capture with headless
  Chrome (`chrome --headless=new --screenshot`), crop with PowerShell (no Python here). Fictional data only.
- Langfuse: open the existing Arabic negotiation trace in your Chrome (already signed in to Langfuse Cloud) with
  Claude in Chrome, screenshot the trace panel only, and crop out anything personal (account name, email,
  project id in the URL bar). Shown to you before it goes in the repo.
