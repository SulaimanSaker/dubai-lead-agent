# Plans

Before building a feature, the agent writes a short plan here and the human approves it.
One file per feature: `YYYY-MM-DD-feature-name.md`.

## Template

```md
# <Feature>

**Goal:** one sentence.
**Files to add/change:** list.
**Steps:** numbered, small.
**Tests:** what proves it works.
**Risks / open questions:** anything the human should decide.
**Status:** draft | approved | done
```
